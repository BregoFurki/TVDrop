# TVDrop v1.1.0

## English

- TV and web interfaces now support automatic device language detection and a manual language selector.
- Available languages: English, Turkish, Brazilian Portuguese, Simplified Chinese, Japanese, German, Indonesian, Russian, Spanish and French.
- The TV and phone can use different languages. Manual choices are remembered separately.
- The existing QR pairing, file transfer, received-file list and APK installation flow remain available.

Install `TVDrop-v1.1.0.apk` on an Android TV. Both devices must be on the same trusted local network. Transfers use HTTP and are not encrypted. Files are limited to 2 GB each and need about three times their size in TV free space during transfer.

**Upgrading from a debug APK:** Android will reject an update signed with a different key. Uninstall the debug build before installing this release. Back up files in the app's private storage first; uninstalling the app may delete them.

## Türkçe

- TV ve web arayüzü cihaz dilini otomatik algılar; elle dil seçimi de eklendi.
- Desteklenen diller: Türkçe, İngilizce, Brezilya Portekizcesi, Basitleştirilmiş Çince, Japonca, Almanca, Endonezce, Rusça, İspanyolca ve Fransızca.
- TV ve telefon farklı dillerde kullanılabilir. Elle yapılan tercihler ayrı ayrı hatırlanır.
- QR eşleştirme, dosya aktarımı, gelen dosyalar listesi ve APK kurulum akışı korunur.

`TVDrop-v1.1.0.apk` dosyasını Android TV’ye kurun. Cihazlar aynı güvenilir yerel ağda olmalı. Aktarım HTTP ile yapılır ve şifreli değildir. Dosya başına sınır 2 GB’tır; aktarım sırasında TV’de yaklaşık üç katı boş alan gerekir.

**Debug APK’dan geçiş:** Farklı imza nedeniyle Android güncellemeyi reddeder. Önce debug sürümünü kaldırmak gerekir. Uygulamaya özel klasördeki dosyaları kaldırmadan önce yedekleyin; kaldırma işlemi bu dosyaları silebilir.
