# TVDrop v1.1.1

The TV language button now says **Language** (or its translation, such as **Dil** in Turkish), so its purpose is clear. The current choice remains marked inside the language menu. No change to file transfer or storage.

TV’deki dil düğmesi artık **OTO** yerine **Dil** yazıyor. Diğer dillerde de düğme ilgili dilde adlandırılıyor; seçili dil menü içinde işaretli kalıyor. Dosya aktarımı ve depolama değişmedi.

Install the signed `TVDrop-v1.1.1.apk` from GitHub Releases. An existing **release-signed** v1.1.0 installation can be updated in place. A debug-signed installation still requires uninstalling the debug build first; back up app-private files before doing that.
